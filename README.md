# AmanPOS: Your Offline Cashier

Build for me app for POS cashier under web base, able to manage under offline. User interface contained item code, description, price, unit of measure (pcs,box, etc), quantity, total price. Transaction can be operated with scan barcode and selecting items. Access by login username and password. Also we can access admin page for dashboard monitoring transaction and report. Item can be imported by excel. The name of application is AmanPOS
